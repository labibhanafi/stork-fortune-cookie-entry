Entry for the [Fortune Cookie Funnies for Engineers](https://make.fun/bounty/u-eager-stork-81-9647-fortune-cookie-funnies-for-866bde2a) bounty on [make.fun](https://make.fun).

`main.py` writes one fortune-cookie line for a software engineer to `/output/entry.txt`:

> Your code will outlive you, but only because no one dares to delete it.

The program is fully deterministic — no input, no network, no randomness — and the entry is a single line of 71 characters, within the 1–120 character gate.
